01

An attention router, not another tracker

The board is a projection of session state, never the source of truth. The harness owns execution. FlightDeck makes state, requests for attention, and continuation context visible, then gets out of the way.

Rule 01

A card cannot be dragged done

The UI never writes a native execution state. Lanes are computed from source conditions, so a card moves because the agent moved, not because you dropped it.

Rule 02

Poll, hook, checkpoint

Polling provides correctness. Hooks improve latency. MCP captures the human-meaningful checkpoints. Each layer degrades honestly when a connector fails.

Rule 03

Session is the unit

The session is what executes. Outcome is optional grouping and memory. Child agents stay as activity under a parent and never become top-level cards.

04

State is derived, not declared

Every lane is a deterministic function of a source condition. Precedence resolves the ambiguous cases so a card is never in two places.

Source conditionBoard lane
Native workingIn flight
Native blocked, permission request, or open human decisionNeeds me
Review-ready checkpointReview
Native failedNeeds me
Native doneFinished
Native stopped or confirmed stale sessionParked

Precedence  failure / stopped › open human attention › review ready › working › complete › stale.

A one off missed poll must not park a session. Stale needs a threshold, roughly three missed polls, before a card leaves flight.

05

Where Pulse sits on the deck

Pulse is a new primary surface, not a rewrite. The instruments you already have keep their jobs, Pulse becomes the place you land first.

Pulse Spend Quota Logbook Charts
  • PulseNew. The attention board and the response loop. The default landing surface.
  • LogbookAbsorbs the Finished history and remains the home for full transcripts.
  • ClearanceThe per session drill down you already built becomes the card's deep view.
  • Spend / ChartsUnchanged. Cost and module graph instruments keep their tabs.
Why it earns the front row

Today the operator scans the logbook to infer what a run is doing. Pulse inverts that. It surfaces the one moment that needs a decision and hides everything calm.

  • FindNext human action in under five seconds.
  • AnswerStructured form, delivered to the right session.
